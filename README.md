# COVID-19 Data Analysis

This repository contains a data analysis project focusing on the **COVID-19 dataset** from [Kaggle](https://www.kaggle.com/datasets/meirnizri/covid19-dataset). The project is part of a college assignment and aims to analyze the dataset by dropping low-correlated features using **Principal Component Polarization (PC Polarization)**.

## Project Goals
- Perform **data preprocessing** and **exploratory data analysis (EDA)** on the COVID-19 dataset.
- Use **PC Polarization** to identify and remove **low-correlated** features.
- Visualize and interpret the impact of dimensionality reduction.

## Dataset
- **Source**: [Kaggle COVID-19 Dataset](https://www.kaggle.com/datasets/meirnizri/covid19-dataset)
- **Contents**: Includes confirmed cases, deaths, recoveries, and various other features related to COVID-19.

## Setup
### Prerequisites
Ensure you have the following installed:
- Python 3.x
- Pandas
- NumPy
- Matplotlib & Seaborn (for visualization)
- Scikit-learn (for feature analysis)

## Results
- Feature correlation analysis.
- Dimensionality reduction using PC Polarization.
- Visual insights on data distribution and feature importance.
